# MrClock Donate

USDT (BEP20) donation page + admin + Telegram.

## Install (Ubuntu)

```bash
git clone https://github.com/Mrclocks/DonatePage.git
cd DonatePage
bash install.sh
```

Choose `1`.

Ports: **80**, **443**

## If build fails on Oracle Cloud

```bash
cd DonatePage
git pull
bash install.sh
```

Choose `7` (update) or `1` again. Installer sets Docker DNS automatically.
